# Προσομοίωση Κλιματικής Αλλαγής

Μία διαδραστική εκπαιδευτική εφαρμογή προσομοίωσης της κλιματικής αλλαγής στην Ελλάδα, γραμμένη σε καθαρό **JavaScript + SVG**, χωρίς εξωτερικές βιβλιοθήκες.

Ο φοιτητής επιλέγει ένα **κλιματικό σενάριο** (A2, B2, A1B, RegCM_A1B) και ένα **έτος πρόβλεψης**, και η εφαρμογή σχεδιάζει γραφικά την εξέλιξη της **μέσης ετήσιας θερμοκρασίας** και της **μέσης ετήσιας υγρασίας** από το έτος 2000 έως το έτος-στόχο.

---

## Δυνατότητες

- Δυναμικό **SVG γράφημα** με δύο γραμμές: θερμοκρασία (κόκκινη) και υγρασία (μπλε).
- **Animated σχεδίαση** των γραμμών (αριστερά → δεξιά) με `stroke-dashoffset`
- **Animated αύξηση/μείωση** των αριθμητικών τιμών καρέ-καρέ (`requestAnimationFrame`)
- Διπλός άξονας Υ: **Θερμοκρασία 14°C – 21°C** (αριστερά) και **Υγρασία 30% – 75%** (δεξιά).
- **Αυτόματη πρόβλεψη** κλιματικής κατάστασης βάσει της τελικής θερμοκρασίας.
- **Σύστημα προόδου**: κάθε νέο σενάριο που δοκιμάζεται προσθέτει **25%** (4 σενάρια = 100%).
- Άμεσο **reset** γραφήματος όταν αλλάζει το σενάριο ή ο ολισθητής ετών.

---

## Κλιματικά Σενάρια
Τα σενάρια βασίζονται στo **IPCC-SRES**  (Διακυβερνητική Επιτροπή για την Κλιματική Aλλαγή) και περιγράφουν προβλέψεις για τη θερμοκρασία και μια άλλη μεταβλητή (όπως η βροχόπτωση ή η γεωργική παραγωγή) ανάλογα με τις εκπομπές αερίων του θερμοκηπίου.:

| Σενάριο | Περιγραφή | Άνοδος Θερμοκρασίας / έτος | Μείωση Υγρασίας / έτος |
|---|---|---|---|
| **A2** | Υψηλές εκπομπές, ετερογενής κόσμος | +0.045°C | -0.15% |
| **B2** | Μέτριες εκπομπές, τοπικές λύσεις | +0.022°C | -0.05% |
| **A1B** | Ισορροπημένη αγορά ενεργειακών πόρων | +0.035°C | -0.10% |
| **RegCM_A1B** | Περιφερειακό μοντέλο περιορισμένης περιοχής (RegCM) | +0.039°C | -0.14% |

> **Σημείωση:** Οι συντελεστές είναι προσεγγιστικοί και απλοποιημένοι για εκπαιδευτικούς σκοπούς.

### Πρόβλεψη Κλιματικής Κατάστασης
Η τελική πρόβλεψη προκύπτει από την υπολογιζόμενη θερμοκρασία του έτους-στόχου:

| Τελική Θερμοκρασία | Πρόβλεψη |
|---|---|
| > 18.5°C | Έντονη Ερημοποίηση & Συχνοί Καύσωνες |
| 17.0°C – 18.5°C | Αύξηση Ακραίων Καιρικών Φαινομένων (Medicane) |
| 16.0°C – 17.0°C | Ήπια Κλιματική Μεταβολή |
| ≤ 16.0°C | Σταθερό Κλίμα |

## Οδηγίες Χρήσης
1. Επιλέξτε ένα **κλιματικό σενάριο** από το dropdown.
2. Σύρετε τον ολισθητή για να ορίσετε το **έτος πρόβλεψης** (2000 → όσο μακριά θέλετε).
3. Πατήστε **«Προσομοίωση»**.
4. Παρατηρήστε:
   - Το γράφημα να σχεδιάζεται σταδιακά.
   - Τις τιμές να «μετράνε» μέχρι τις τελικές.
   - Την **πρόβλεψη** που εμφανίζεται στο τέλος του animation.
5. Δοκιμάστε και τα **4 σενάρια** για να φτάσετε στο **100%** προόδου!

## Τεχνική Περιγραφή

### Πώς λειτουργεί
1. **`drawAxesOnly()`** — Σχεδιάζει το υπόβαθρο: γραμμές πλέγματος, άξονες θερμοκρασίας/υγρασίας και τα κενά `path` των γραμμών.
2. **`runSimulationData()`** — Συλλέγει τις εισόδους, υπολογίζει τις τιμές ανά **5ετία** (γραμμικό μοντέλο) και καλεί το σχεδιασμό και τα animation.
3. **`animatePathDrawing()`** — Η τεχνική `stroke-dasharray` / `stroke-dashoffset` με CSS transition 4 δευτ. για ομαλή σχεδίαση.
4. **`animateResultValues()`** — Γραμμική παρεμβολή των τιμών ανά καρέ με `requestAnimationFrame` (διάρκεια 4 δευτ.).
5. **`drawChartData()`** — Μετατροπή δεδομένων σε SVG `Path` commands (`M`, `L`) και ετικέτες ετών στον άξονα Χ.
6. **`resetChartAndResults()`** — Καθαρισμός γραφήματος και ακύρωση τρεχόντων animations.

### Απαραίτητα HTML στοιχεία
Το `<script>` περιμένει να υπάρχουν στη σελίδα τα εξής:

| ID | Στοιχείο |
|---|---|
| `customSvgChart` | `<svg>` όπου σχεδιάζεται το γράφημα |
| `scenarioSelect` | `<select>` με επιλογές `A2`, `B2`, `A1B`, `RegCM_A1B` |
| `yearSlider` | `<input type="range">` για το έτος πρόβλεψης |
| `runBtn` | `<button>` «Προσομοίωση» |
| `instructions` | `<div>` όπου εμφανίζονται οι animated τιμές & η πρόβλεψη |
| `scoreText` | Στοιχείο που δείχνει το ποσοστό προόδου |

### Απαραίτητο CSS
```css
.animated-line {
  transition: stroke-dashoffset 4.0s ease-out;
}
```
